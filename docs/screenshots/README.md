# Screenshots

The main README embeds four images from this folder. Capture them from a running
instance (`docker compose up --build`, then <http://localhost:8000>) and save with
exactly these filenames:

| File | What to capture |
|---|---|
| `forecast.png` | Forecast page: current-quarter ranking + quarter-to-date tracking |
| `backtest.png` | Backtest page: $100 growth curve vs the four baselines + metric tiles |
| `filings.png`  | A filing with its extracted effects and verbatim evidence quotes |
| `extract.png`  | The live extraction demo mid-run or with a finished digest |

Full-window captures at ~1440px wide render well in GitHub's README column.
